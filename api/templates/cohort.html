Study premise · why this cohort needs measuring

Representation gap

"Localization" here means audience localization: the cohort's multilingual consumption profile, which differs structurally from the English-dominant default global recommenders assume.

{% call ui.method("Why not Nepali cinema?") %}

The catalogue holds exactly one Nepali title out of {{ '{:,}'.format(catalogue_size) }} (Manakamana, 2013, a documentary with 12 votes), so no claim about surfacing Nepali cinema is testable here. Supplementing the catalogue was ruled out: no cohort user prefers Nepali, no rating exists for any Nepali film so a title can never be a held-out positive, and language affinity is estimated as consumption lift, which pins Nepali at the floor at any catalogue size.

{% endcall %}

Affinity tables: hand-set prior vs derived

The affinity weights are not hand-tuned — they are estimated from data, and the estimate inverts the prior.

{% call ui.method("How the derived table is estimated") %}

Affinity is estimated as cross-archetype consumption lift on users excluded from the cohort, which is what keeps the scorer independent of the generator. The hand-set prior is retained only as a fallback and as a comparison — and it ranked English highest and Nepali lowest, the exact opposite of the study's premise. The derived table inverts it.

{% endcall %}
